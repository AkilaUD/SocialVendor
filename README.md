# Social Seller OS

High-fidelity interactive prototype for a Sri Lanka–focused social commerce operating system — chat-to-order, COD reconciliation, courier waybills, returns, and profit after costs.

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · React Router · Zustand · GSAP · Motion · Radix UI · Recharts · React Hook Form · Zod · Sonner

## Run

```bash
npm install
npm run dev
```

## Demo path

1. Open `/` — marketing site + RTO calculator  
2. **Open demo desk** or `/login` → skip OTP  
3. Complete onboarding → `/app` desk for **Lanka Loom Atelier**  
4. Try **Quick order**, **Dispatch**, **COD match**, **Returns**, **Tickets**  
5. Public demos: `/track/KOOM-552101`, `/store/lanka-loom`

All data is local mock state — no backend.
